This was my first experience working with TypeScript, although I had a very small amount of previous experience with JavaScript. Because of this, TypeScript was somewhat new to me, but my JavaScript experience helped me understand some of the basic syntax.

I learned how TypeScript adds types to JavaScript, which can make code easier to understand and help catch mistakes earlier. From a software engineering perspective, I think TypeScript is a good programming language because it provides more structure to JavaScript.

For athletic software engineering, I found the WODs were definitely better for me as a software engineer because they gave me a way to practice the concepts of TypeScript through actual coding instead of only reading about them.

The WODs were very stressful, though, because there is a very short time limit. Thinking of an approach and debugging your code can take a long time, especially when you are still learning the language. However, I also think the WODs help improve problem-solving skills and coding speed.

Overall, I think this type of learning can work well for me because it gives me hands-on practice and helps me become more comfortable with programming. I think having a little more time for the WODs would make the experience less stressful while still keeping the benefits of this style of learning.
